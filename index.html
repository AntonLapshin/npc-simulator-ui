NPC Simulator UI

Standalone visual scene library — objects, characters and the 2.5D renderer, driven by raw JSON. No engine, no network.

Object gallery

Every object in isolation, fixed 3/4 top-down view (everything faces south). The Character page has a full config panel: pose, look, props, speech.

Scene preview

Full scenes with a sample cast, bubbles and pose/emotion controls — the workbench for polishing the look. Deep-linkable via ?scene=..&char=..&pose=...

Library entry: js/render/index.js (SceneRenderer, getScene, OBJECTS). Serve with npm start → http://localhost:8123/. Details in README.md.
